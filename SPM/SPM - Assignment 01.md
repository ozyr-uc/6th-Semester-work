# Part A — Project Introduction & Scope

## 1. Problem Statement

Many universities still use manual or semi-digital methods for assignment submission and management. These methods create problems such as:

- Late submissions
- Misplaced assignments
- Difficulty in tracking submissions
- Lack of centralized storage
- Poor communication between students and instructors

> The proposed system will provide a cloud-based platform where students can submit assignments online and teachers can manage, review, and grade them efficiently.

---

## 2. Project Objectives

The main objectives of the project are:

- Develop a centralized online assignment management system
- Allow students to upload assignments securely
- Enable teachers to review and grade assignments online
- Reduce paperwork and manual management
- Provide deadline notifications and submission tracking
- Improve communication between students and instructors

---

## 3. Project Scope

### In-Scope Items

- User authentication system
- Student dashboard
- Teacher dashboard
- Assignment upload feature
- Deadline management
- File storage on cloud server
- Assignment grading and feedback
- Notifications for deadlines and submissions

### Out-of-Scope Items

- Video conferencing features
- Online exam/proctoring system
- AI-based plagiarism detection
- Mobile application development
- Payment integration

# Part D — Stakeholders & Success Criteria

# 1. Stakeholders and Their Roles

| Stakeholder | Role |
|---|---|
| Students | Submit assignments and view feedback |
| Teachers/Instructors | Create assignments, review submissions, and grade work |

---

# 2. Project Success Criteria

The project will be considered successful if:

- Students can successfully upload assignments
- Teachers can review and grade submissions efficiently
- The system remains stable and secure
- Assignment deadlines are managed correctly
- User data is stored safely on the cloud
- The system reduces manual workload
